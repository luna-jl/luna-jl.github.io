JavaScript / React Chart Library Comparison

A working reference for picking a charting library, current as of August 2026. Bundle sizes and licensing terms shift between releases — verify against the library's own docs before locking in a decision on anything license-sensitive (Highcharts, LightningChart).

Library Approach Rendering License Approx. bundle Framework Maturity
TanStack Charts Headless grammar-of-graphics (compose marks/scales, not chart types) SVG + Canvas MIT ~38–44 KB Framework-agnostic core Pre-alpha — repo explicitly says not production-ready
Chart.js Pre-built chart types (9 core types + plugins) Canvas MIT ~45–58 KB Framework-agnostic (react-chartjs-2, vue-chartjs wrappers) Mature — most popular JS charting lib by downloads (~4M/wk)
Recharts Declarative React components over D3 SVG MIT ~150–170 KB (component-only; more with React itself) React only Mature — the default pick for React dashboards (~1.8M/wk)
Apache ECharts Pre-built, huge catalogue (40+ chart types incl. maps, Gantt, Sankey) Canvas, WebGL extension for large data Apache 2.0 ~150–175 KB full; much smaller with per-chart-type imports Framework-agnostic, community React/Vue wrappers Mature — best variety-to-cost ratio, handles large datasets well
D3.js Low-level primitives — scales, shapes, layouts, geo projections SVG, Canvas, or WebGL — your choice ISC ~90 KB gzip full; small if you import only needed modules Framework-agnostic Mature — the toolkit everything else above is often built on. Steepest learning curve, max control
visx D3 primitives exposed as React components (built by Airbnb) SVG MIT ~49 KB gzip React only Mature but low-level — you're assembling charts, not consuming them
Nivo Declarative React chart components built on D3 SVG, Canvas, and HTML variants per chart MIT ~186 KB React only Mature — best out-of-the-box visual polish + accessibility
Observable Plot High-level grammar-of-graphics on top of D3 (same team as D3) SVG ISC Lightweight, modular Framework-agnostic Mature within scope — great for fast exploratory/one-off charts, less for bespoke interactive dashboards
Plotly.js Broad scientific/statistical charting (3D, geo, statistical) SVG + WebGL (via regl) MIT Heaviest of the group — bundles D3 + regl + a scientific stack Framework-agnostic, official React wrapper Mature — go-to for scientific/statistical plots and 3D, overkill for a simple dashboard chart
Highcharts Pre-built enterprise chart library, 40+ types SVG Commercial $185–366+/dev/yr (free for non-commercial/education) Moderate Framework-agnostic, official React/Vue/Angular wrappers Mature — since 2009. Best accessibility (WCAG) and export tooling, but licensing is the gate
LightningChart JS Pre-built, GPU-accelerated, built for extreme data volumes WebGL/GPU Commercial (free non-commercial tier) Moderate–heavy Framework-agnostic, official React wrapper Mature — the only one on this list that handles 10M+ point datasets smoothly

Bundle sizes are approximate gzip figures compiled from public benchmark write-ups (TanStack's own comparison suite, PkgPulse, LightningChart's alternatives roundup) and shift with each release — treat the ordering as more reliable than the exact KB numbers.

Quick picks by scenario

  • React SaaS dashboard, standard charts, ship fast — Recharts. Idiomatic JSX, MIT, huge ecosystem familiarity.
  • Vanilla JS / framework-agnostic, smallest footprint, standard chart types — Chart.js.
  • Need a huge catalogue of chart types (maps, Gantt, Sankey) or must handle large datasets on a budget — Apache ECharts.
  • Fully bespoke / novel visualization, no off-the-shelf chart fits — D3.js directly, or visx if you're in React and want D3 power with JSX ergonomics.
  • Want beautiful defaults + accessibility without hand-tuning — Nivo.
  • Quick exploratory/one-off chart, not a long-lived interactive component — Observable Plot.
  • Scientific, statistical, or 3D plotting — Plotly.js.
  • Enterprise budget, need WCAG compliance and vendor support out of the box — Highcharts.
  • Real-time or 10M+ point datasets (trading, sensor telemetry) — LightningChart JS (WebGL/GPU).
  • Curious / experimenting, already in the TanStack ecosystem, not shipping to prod soon — TanStack Charts. Smallest bundle of the bunch and a genuinely interesting grammar-of-graphics API, but it's pre-alpha — expect breaking changes and don't put it in front of customers yet.
